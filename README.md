## Get them

Every plugin below has a release page, and the **Latest** badge always shows the current version. Browse, search and install from the **[plugin store](https://sd88me.github.io/mpc-vst-plugins/)** or follow the **[install guide](https://sd88me.github.io/mpc-vst-plugins/install.html)**. Plugin names link to their store page.

> Plugins that emulate hardware never ship ROMs or firmware. Where one needs ROM files, you supply your own.
