## Get them

Every plugin below has a release page, and the **Latest** badge always shows the current version. Browse, search and install from the **[plugin store](https://open-mpc.github.io/)** or follow the **[install guide](https://open-mpc.github.io/install.html)**. Plugin names link to their store page. Download counts come from the plugin store (182,200 in total across my plugins, as of 2026-11-20).

> Plugins that emulate hardware never ship ROMs or firmware. Where one needs ROM files, you supply your own.
